# 🎬 Вертикальний відеоплеєр у фоторамці (9:16)

Лаконічний плеєр: на екрані знаходиться **виключно відео в розкішній фоторамці** без будь-яких зайвих кнопок чи меню.

---

### 📥 Як додати відео:
1. Покладіть ваше відео прямо в цю папку (`happy birthday video`).
2. Назвіть файл **`video.mp4`** (підтримуються також `.mov` та `.webm`).
3. Відкрийте файл [**`index.html`**](index.html) — відео почне грати у фоторамці!

*(Навіть якщо сторінка плеєра вже відкрита, коли ви скопіюєте `video.mp4` у папку, плеєр автоматично виявить його за 2 секунди).*

---

### ⌨️ Керування:
- **Клік по екрану** або **Пробіл** — Пуск / Пауза
- **Подвійний клік** або клавіша **F** — Повний екран (Fullscreen)
- **Клавіша M** — Увімкнути / вимкнути звук
- **Стрілочки вліво / вправо** — Перемотка на 5 сек вперед / назад
- Елементи керування (прогрес-бар, гучність) плавно приховуються під час перегляду, щоб не відволікати від відео.
